## The 30-Second Pitch

> Financial fraud is not one problem. It is a **transaction** problem, a **behavior** problem, a **network** problem, and a **trust** problem.
> **QuantumFinGuard** addresses all four in one platform: ML detection, explainable decisions, behavioral baselines, blockchain graph investigation, and tamper-evident security with post-quantum cryptographic mechanisms.

It is not a cryptocurrency, a mining platform, a quantum-computing project, a plain dashboard, or a single ML model.

## Limitations

- This is an academic capstone project, not a production financial system.
- Frontend screens and final API integrations are still being completed.
- The Neo4j work is an integration effort for the investigation layer; no live production deployment is claimed.
- Reported ML metrics come from the verified run on IEEE-CIS and may differ on other data.
- Post-quantum mechanisms are incorporated as security considerations, not as a guarantee of quantum resistance.
